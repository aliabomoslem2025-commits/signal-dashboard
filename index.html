SECURITY NOTICE

Android ID is not an authenticator. Login is permitted only when the phone number and Android ID match a pre-enrolled device and the device proves possession of its Android Keystore private key. Never enroll a device using an unverified public key from an untrusted source.

This dashboard controls the Local Device Authentication service. It does not replace the Signal server's account-registration adapter or the Android app integration by itself.
